# Tourism-Management-System
A web-based Tourism Management System for managing tourist destinations, tour packages, hotel bookings, customer details, billing, and online payments using C#DotNet and Sql Server Management 
🌍 Tourism Management System

A desktop-based Tourism Management System developed using C#.NET and Microsoft SQL Server to simplify and manage tourism operations.

---

📌 About the Project

The Tourism Management System is designed to manage essential tourism activities through a user-friendly application. It helps organize tourist destinations, tour packages, customer registrations, hotel information, bookings, billing, and payment details.

The application provides separate login access and workflows for administrators, tour operators, and customers.

✨ Features

- 🔐 Login System — User authentication and role-based access.
- 🛡️ Admin Management — Manage tour operator registrations and maintain tourism information.
- 👤 Customer Management — Register customers and maintain customer records.
- 🌍 Destination Management — Add and manage tourist destination details.
- 🧳 Tour Package Management — Create, update, and manage tour packages.
- 🏨 Hotel Management — Store hotel information and manage hotel bookings.
- 📅 Booking Management — Book tour packages and track booking details.
- 🧾 Billing Management — Generate and manage customer bills.
- 💳 Payment Management — Maintain and validate payment information.
- 📊 Dashboard — Display relevant booking and tourism activity information.

🗄️ Database

This project uses Microsoft SQL Server to store and manage tourism-related information.

The database can include customer details, destination information, tour packages, hotel information, booking records, billing details, and payment information.

Database Setup

1. Open SQL Server Management Studio (SSMS).
2. Connect to your SQL Server instance.
3. Create the required database if it does not already exist.
4. Open and execute the project’s SQL database script, if available.
5. Verify that the required tables and relationships have been created.
6. Update the application's connection string according to your SQL Server configuration.

Note: Ensure that the database script contains the necessary table definitions and relationships. The database name and connection string should match your actual project configuration.

🚀 How to Run the Project

1. Download or clone the GitHub repository.
2. Open the project solution file (".sln") in Visual Studio 2012.
3. Set up the database using Microsoft SQL Server.
4. Update the database connection string in the application.
5. Build the project in Visual Studio.
6. Run the application and test the available features.
